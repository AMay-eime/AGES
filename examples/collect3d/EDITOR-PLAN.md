# エディタ計画書 — collect3d（3D のサンプル）

追加パッケージ 3d の動作確認用サンプル。3人称視点で、足場を渡ってコインを集める。
実際のプロジェクトでは `ages init` で作られるひな形を、AIが使用者に確認しながら埋める。

## 0. 進め方
- [ ] 一緒に決める
- [x] AIにおまかせ（サンプルなので。手触りの数字は、触る人がインスペクタで決め直す）

## 1. ゲームの概要
- ジャンル: 3人称視点のアクション（足場を渡って物を集める。最小構成）
- 面白さの核: 跳んで足場を渡り、コインを全部集める
- 手触りで大事にしたいこと: 歩く速さ・跳ぶ高さ・落ちる速さ（重さ）
- 画面: 960x540 横

## 2. 何度も調整するもの
| 何を | どのコンポーネントの値にするか | 範囲の目安 |
| --- | --- | --- |
| 歩く速さ | Player.speed | 0..20 m/秒 |
| 跳ぶ強さ | Player.jump | 0..30 m/秒 |
| 落ちる強さ | Player.gravity | 0..100 m/秒² |
| 向きを変える速さ | Player.turn | 0..3600 度/秒 |
| カメラの位置と遅れ | main#camera.Camera3D.offset / lag | — |
| コインの回る速さ | @coin.Spin.speed | -1440..1440 度/秒 |

## 3. 表や行列で扱うもの
なし（足場とコインはシーンに置く）

## 4. 必要なエディタウインドウ
なし。足場・コイン・光の配置は標準の「3D シーン」パネル（視点・ギズモ）、数字はインスペクタで足りる。

## 5. 素材
