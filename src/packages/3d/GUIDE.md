# 追加パッケージ 3d の手順（入れているプロジェクトでだけ、ages schema <dir> guide:項目 で引ける）

## 3d: 3D の全体
- 追加パッケージ 3d は作っている途中（docs/PLAN.md の段階4）。いまは仕組みだけで、3D の部品（位置・カメラ・モデル・光）はまだない。3D のゲームは、部品がそろうまで作り始めない（使用者に伝える）
- 決まっていること: 座標は glTF と同じ（Y が上・右手系・単位はメートル）。描画は WebGL2。2D の UI（HUD・メニュー）は 3D の上にそのまま重なる。物理（押し返し・重力）は本体にない（当たり判定の問い合わせだけ。動きはゲームのコードで書く）
- ゲームのコードからは `import { … } from 'ages/3d'`
