# 互換の記録（AGES を上げたときの、プロジェクトの直し方）

プロジェクトの `ages.project.json` の `engine.compat` が、そのプロジェクトが合わせてある互換の番号。今の本体の番号（`src/project/version.ts` の `COMPAT`）と違うと、`ages check` とエディタが知らせる。

**AI の手順**: `ages version <dir>` で、記録の番号の次から今の番号までの項が出る。上から順に「プロジェクトで直すこと」を行い、`ages check` と `ages run` で確かめてから `ages version <dir> --record` で記録を今の番号に合わせる。

## 書き方（AGES を直す人へ）

- 今までのプロジェクトに直しが要る、または動きが変わる変更（部品・欄・命令・ctx の名前や意味が変わる・消える、既定の値が変わる、標準のシステムの動きが変わる、ファイルの形が変わる）をしたら、ここに項を足し、`COMPAT` を1つ上げる（`test/version.test.ts` が番号のずれを見つける）
- 足すだけの機能（今までのプロジェクトがそのまま同じに動く）は書かない
- 項の見出しは `## 番号. 日付 何が変わったか`。中身は「変わったこと」「プロジェクトで直すこと（AI がそのまま行える手順。`ages patch` の op・置き換える名前・探す場所）」「直さないとどうなるか」

## 1. 2026-11-10 記録の始まり

- 変わったこと: この記録を始めた。これより前に作ったプロジェクトには `engine` の記録がない
- プロジェクトで直すこと: なし。`ages version <dir> --record` で今の番号を残す

## 2. 2026-11-10 dist/ は書き出しの置き場所

- 変わったこと: `ages export`（書き出し）を足し、書き出したものを `dist/` に置くようにした。`dist/` はアセットとして読まない（アセットの一覧・地図・エディタのファイルの一覧に出ない）。アセットを `dist/` の下に新しく置くこともできない
- プロジェクトで直すこと: `dist/` を使っていなければ、何もしない（`.gitignore` の `dist/` は `ages export` が足す）。`dist/` の下にアセット（画像・音・フォント・シェーダー）があれば、上げた後の本体からは見えないので、ファイルを `assets/` の下へ移し（`git mv dist/a.png assets/a.png` など。切り方の `.sheet.json` も一緒に）、`ages check` がエラーを出す値を `ages patch` の `set` で新しい場所に直す
- 直さないとどうなるか: `dist/` の下のアセットが見つからなくなり、`ages check` がそれを使う値のエラーを出す
